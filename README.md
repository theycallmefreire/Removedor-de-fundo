## Instalação
1. Clonagem do repositorio:
```bash
git clone https://github.com/theycallmefreire/Removedor-de-fundo.git
```
2. Instale as dependencias:
```bash
pip install -r requirements.txt
```
---
## Como usar
1. rode a main.py.
2. responda "sim" ao prompt, caso contrario ele vai fechar o programa.
<img width="503" height="26" alt="image" src="https://github.com/user-attachments/assets/96474bbb-8550-4783-be77-1f531a523f11" />

3. Vai abrir uma janela, procure sua imagem(uma por vez).
